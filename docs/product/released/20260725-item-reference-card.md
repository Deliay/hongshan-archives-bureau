# 搜索结果物品参考卡片

**功能名称**: 搜索结果 Item Reference Card
**PRD 版本**: v1.0
**创建日期**: 2026-07-25
**作者**: 产品

## 背景与目标

### 1.1 背景

当前搜索结果中，来自 `ItemTable` 的命中结果仅展示一个极简的物品卡片（图标 + 名称 + 稀有度），与武器卡片完全一致。用户无法从搜索结果中快速识别物品类型（材料、消耗品、收集品等），需要额外点击才能获取基础分类信息。

### 1.2 目标

- 增强搜索结果中的物品参考卡片，在基础信息区展示物品类型。
- 保持与现有 `SkillReferenceCard`、`TalentReferenceCard` 一致的视觉风格。
- 不增加用户操作负担，信息展示为纯展示型，无需额外交互。

### 1.3 成功标准

- 搜索结果中来自 `ItemTable` 的命中项展示物品类型标签。
- 物品类型名称跟随当前语言设置正确显示。
- 卡片样式与现有的武器、干员、敌人参考卡片风格统一。

## 用户分析

### 2.1 目标用户

- 通过关键词搜索查阅物品相关信息的玩家与编辑者。
- 需要快速区分物品类型（材料 vs 消耗品 vs 收集品）的研究者。

### 2.2 用户场景

| 场景 | 用户角色 | 目标 | 痛点 |
|--|--|--|--|
| 搜索某个材料名称 | 数据校对者 | 确认该材料在哪些文本中被提及，并快速识别其类型 | 当前卡片不显示类型，需额外点击确认 |
| 搜索关键词命中多个物品 | 剧情研究者 | 快速区分命中的物品是材料、消耗品还是收集品 | 所有物品卡片外观相同，无法区分 |

## 功能需求

### 3.1 功能概述

在搜索结果的物品命中项中，展示包含物品类型的基础参考卡片。卡片包含物品图标、名称、稀有度星级和物品类型标签。

### 3.2 功能列表

#### 功能点 1: 物品参考卡片增强

- **描述**: 搜索结果中来自 `ItemTable` 的命中项，其参考卡片从当前的极简样式升级为包含物品类型的基础信息卡片。
- **用户价值**: 无需点击即可识别物品类型，提升搜索结果的信息密度。
- **验收标准**:
  - [ ] 物品卡片展示图标、名称、稀有度星级、物品类型标签。
  - [ ] 物品类型名称从 `ItemTypeTable` 获取并正确 i18n。
  - [ ] 卡片整体样式与武器、干员、敌人参考卡片风格统一。
  - [ ] 卡片点击后跳转至 `/archive/items` 物品列表页。

### 3.3 页面/界面描述

| 元素 | 说明 |
|------|------|
| 物品图标 | 左侧，10×10，带稀有度边框 |
| 物品名称 | 右侧第一行，截断显示 |
| 稀有度星级 | 右侧第二行，使用 `Rarity` 组件 |
| 物品类型标签 | 右侧第三行，小字灰色标签 |

### 3.4 异常与边界情况

| 情况 | 预期行为 |
|------|---------|
| `ItemTypeTable` 数据未加载 | 类型标签不显示，不阻塞卡片渲染 |
| 物品类型 ID 无对应 i18n | 显示类型 ID 数字作为 fallback |
| 物品图标加载失败 | 使用默认占位图标 |

## 非功能需求

### 4.1 性能要求

- 物品类型数据优先走现有缓存，不新增额外请求。
- 类型数据在搜索结果渲染时按需获取，不影响搜索响应速度。

### 4.2 兼容性要求

- 多语言跟随全局语言切换，物品类型名称随语言变化。
- 桌面端与移动端布局一致。

## 依赖与约束

### 5.1 依赖

- 现有 `ItemTypeTable` 表数据接口。
- 现有 `I18nDict` 字典接口。

### 5.2 约束

- 不新增后端接口。
- 不修改现有数据模型与适配器返回值结构。
- 不改动搜索结果的整体布局与交互逻辑。
