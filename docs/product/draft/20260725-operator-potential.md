# 干员潜能模块

## 背景

当前干员详情页未展示潜能相关信息。潜能系统是干员成长的核心维度之一，每级潜能会解锁新效果（天赋增强、属性提升等），部分等级还会解锁专属立绘。管理员需要在详情页查看完整的潜能信息。

## 目标

1. 在干员详情页新增「潜能」模块，展示 5 级潜能的完整信息
2. 每级潜能展示：名称、效果描述、升级材料、解锁立绘（如有）
3. 立绘伴随对应潜能等级展示，而非独立区域

## 用户故事

- 作为管理员，我希望在干员详情页查看每级潜能的名称和效果，了解潜能带来的增益
- 作为管理员，我希望看到每级潜能的升级材料，便于规划资源
- 作为管理员，我希望在对应潜能等级旁看到解锁的立绘，直观感受潜能解锁的视觉奖励

## 产品规格

### 模块位置

在干员详情页中，「潜能」模块位于「干员天赋」之后、「后勤技能」之前。

### 潜能等级列表

每个干员有 5 级潜能（1-5），纵向排列展示。每级潜能为一个卡片，包含：

```
┌─────────────────────────────────────────────┐
│ ⬤ 潜能名称                    [材料图标 ×N] │
│ 效果描述文字...                              │
│                                             │
│ ┌───────────────────────────────────────┐   │
│ │                                       │   │
│ │           潜能立绘 (大图)              │   │ ← 仅 1/3/5 级有
│ │                                       │   │
│ └───────────────────────────────────────┘   │
└─────────────────────────────────────────────┘
```

- **潜能标识**：左侧圆点，带等级数字（1-5）
- **潜能名称**：来自 `CharacterPotentialTable.potentialUnlockBundle[].name`（i18n）
- **效果描述**：来自 `PotentialTalentEffectTable.desc`（i18n），带黑板数值格式化
- **升级材料**：物品图标 + 数量，来自 `potentialUnlockBundle[].itemIds/itemCnts`
- **潜能立绘**：仅在有 `unlockCharPictureItemList` 的等级展示，图片路径 `pic_{level}_{charId}.png`

### 立绘展示规则

- 潜能 1/3/5 级通常解锁立绘，2/4 级无立绘
- 立绘在对应潜能卡片内展示，紧随效果描述和材料之后
- 立绘使用大图（largesize），宽度撑满卡片，高度自适应
- 部分干员在潜能 1 级可能解锁多张立绘（如 `item_pic_1_chr_0004_pelica` + `item_pic_1_ex01_chr_0004_pelica`），全部展示

### 数据来源

| 数据 | 表名 | 说明 |
|------|------|------|
| 潜能等级、名称、材料、图片列表 | `CharacterPotentialTable` | 按 charId 查询 |
| 潜能效果描述、黑板数值 | `PotentialTalentEffectTable` | 按 potentialEffectId 查询 |
| 潜能立绘图片 | 静态资源 | `spaceship/imageposter/largesize/pic_{level}_{charId}.png` |

## 验收标准

1. 干员详情页显示「潜能」模块，位于天赋与后勤技能之间
2. 5 级潜能全部展示，每级显示名称、效果描述、材料
3. 有立绘的潜能等级（1/3/5）在卡片内展示立绘大图
4. 无立绘的潜能等级（2/4）不显示图片区域
5. 多语言环境下潜能名称和效果描述正确显示
6. 立绘图片加载失败时优雅降级（隐藏图片区域）
